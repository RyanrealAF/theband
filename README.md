# THEBAND

A portrait-format, stem-reactive animated band driven by guitar, piano, drums, and bass.

## Concept

Audio is analyzed into musical events, events drive four performers, and performers drive the environment.

- Piano: ghost in the sky behind an edge-to-edge keyboard.
- Guitar: scrap-built showoff with reactive strings and sparks.
- Drums: chaotic goblin with a shopping-cart kit.
- Bass: massive dumpster creature whose low end moves the ground.

Architecture: audio -> analysis -> events -> performers -> world.

The first scaffold uses procedural rendering so behavior can be built before final artwork.

Run with npm install, then npm run dev.
